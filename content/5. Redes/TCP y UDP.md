# **Transmission Control Protocol**
- Orientado a la confiabilidad 
- Garantiza que los datos lleguen sin errores
- Si un paquete se pierde se pausa
- Es más lento
- Se usa en páginas web

# **User datagram protocol** 
- Protocolo sin conexión
- Enfocado a la velocidad
- No se para para asegurar que llegan 
- Se usa donde si se pierde un paquete no pasa nada en [[ROS2]]  
Los [[Firewall]] los gestionan de forma independiente.
